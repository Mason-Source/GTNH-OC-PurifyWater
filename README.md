# PurifyWater

GTNH 净水线自动控制程序（OpenComputers）。一台 OC 电脑接上 ME 网络接口、能量仓和各级水厂，
程序自己读水位、测本轮并行、算功率、下发开关，把 8 级净水厂的水量维持在你设定的阈值上。

## 特色

- **事件 + 时钟双驱动**：高兼容性，理论支持任意状态启动程序进行连接，旧水厂调度焕新友好。
- **两套调度模式**：**阈值调度**（水位低于阈值就开）与**速率调度**（给各级填权重，按"权重链条 + 功率"
  整体缩放算出每台建议并行）；总览控制面板「模式」按钮行左键切模式、右键切子参数（阈值模式 = 高低优先，
  速率模式 = 是否受阈值约束），切换即存 `data/settings.txt`。
- **并行靠本轮实测**：连续 N 个运行周期一致才采用；停机、暂停、换能源仓或增删单元后重新从建议值学习。
- **安全优先**：硬件缺失 / 主机总开关关闭 / 开关与调度意图不符 → 停机 + 锁定，**不自动恢复**，
  处理完手动点【启动系统】；锁定期只保留只读逻辑（采集、界面、日志）。
- **镜像端**：`monitor.lua` 用另一台电脑 + 无线网卡显示同一份快照，不参与调度。
- **开机自启**：配置页勾选「开机自启动」，程序就把启动行写进 `/home/.shrc`（取消勾选自动移除，
  其它内容一行不动）；开机后自动跑起来，按 Q 退出回到 shell，下次开机照常自启。

## 目录

| 目录 | 内容 |
|---|---|
| `installer.lua` | **稳定引导器**：每次运行自动获取最新 `installer_core.lua` 并执行 |
| `installer_core.lua` | 实际安装器核心，由引导器下载，成功后自动删除 |
| `PurifyWater/` | **带注释的源码**（要改就改这里） |
| `build/` | 同一份源码**去注释后的版本**，整份丢进 OC 电脑的 `home/` 就能跑 |

## 快速开始

### 一键安装（推荐，需因特网卡）

在 OC 电脑上：

```bash
wget -f https://raw.githubusercontent.com/Mason-Source/GTNH-OC-PurifyWater/main/installer.lua installer.lua
lua installer.lua
```

装到「当前目录/PurifyWater」，默认拉 `build/`（去注释版）；想要带注释的源码，运行：

```bash
lua installer.lua --source=PurifyWater
```

装完：

```bash
cd PurifyWater
lua main.lua          # 启动（按 Q 退出）；--debug 打开调度/采样细节
```

> 想让电脑开机就自动运行：进【配置】页 →「运行设置」→ 点一下「开机自启动」（写入 `/home/.shrc`，
> 下次开机生效）；再点一次即取消。自启状态只看 `.shrc` 里那段标记块，重启程序即所见即所得。

安装器使用清单同步代码，会清理上游已删除或改名的旧文件；`data/`（阈值、权重、曲线、痕迹）
不会被碰。下载和替换失败时，旧代码保持不变。

下载默认走 GitHub 直连；**直连失败会自动整体切到备用镜像**，
整轮跑完仍有失败项就再来几轮（默认 3 轮，每轮每个文件只试一次，不在同一个文件上死磕）。

万一还是报失败：加 `--debug` 重跑一遍（`lua installer.lua --debug`），完整过程会写进 **`installer.log`**
（启动安装器的那个目录里）—— 每一行都带轮次、网址和原因，屏幕上滚掉的东西都在里面；
不加 `--debug` 的普通安装不写这份日志。

### 手动放置

把 `build/`（或 `PurifyWater/`）整个目录放到 OC 电脑的 `home/` 下：

```bash
cd /home/PurifyWater
lua main.lua              # 控制端（按 Q 退出）
lua main.lua --debug      # 打开 debug 级日志（调度/采样细节）
lua monitor.lua [端口]    # 镜像端（另一台电脑 + 无线网卡，不调度）
```

**首次启动不需要任何配置文件**：`data/settings.txt` 会按「阈值 0 + 全部勾选」自动生成
（键 `threshold.N` / `enabled.N`），此时实际阈值仍受下一级 N 倍保供线约束；
先到配置页把各档阈值填上再点【启动系统】。

> 想用速率调度：总览控制面板「模式」按钮行左键切到速率调度，再到配置页「速率权重」卡给各级填权重
> （0-100 的整数；填 0 = 本级不主动补水，只在下游需要时当"过路级"）。**建议并行一变系统会全关 + 锁定**，
> 按新建议把机器并行调好，再点【启动系统】继续。

## 环境

GTNH 2.8.4以上； OpenComputers：T3机箱 T3显示屏 T3APU（=T4CPU+T3显卡） 无线网卡 内存≥2MB（=T3.5内存*2）。

内存实测：**2048K（2MB）才稳定** —— 1024K 能启动，但半小时内会崩；
